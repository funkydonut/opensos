Creator roadmap — manual steps + progress tracking
====================================================

Purpose
-------
This file lists what YOU (the project owner) must do outside the repo:
Supabase/Vercel dashboards, secrets, and final approval. The coding agent
can mark "agent verified" items after checking the codebase or a successful
local/build check — but only YOU can complete dashboard/account steps.

How to use checkboxes (creator + agent)
-----------------------------------------
- [ ] = not done   |   [x] = done
- Creator-only lines (Sections A–F, except "Agent can verify" rows):
    Mark [x] ONLY after you completed the step in the real dashboard / account.
- "Agent can verify" rows:
    Agent may mark [x] after confirming the claim in the repo or a clean build,
    NEVER as a substitute for a creator step.
- Append one line to "Progress log" with date | who | what was done.
- Optional inline date next to a checkbox, e.g. [x] 2026-05-02
