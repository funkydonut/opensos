How to use checkboxes (agent + creator)
---------------------------------------
- [ ] = not done   |   [x] = done
- A line is marked [x] only when ALL of these are true:
    1. The code (or doc artifact) for that prompt exists in the repo.
    2. `npm run build` is green locally.
    3. The behavior matches the referenced spec — not just "imports compile".
- Agent: only marks [x] in this file (coding prompts).
- Creator: validates in browser / production and appends a line to "Progress log".
- Partial work stays [ ]; add a one-line note under the prompt to describe what is missing.
